# FreeReading

FreeReading 是使用 **Kotlin 和 Jetpack Compose** 开发的 Android 原生本地 EPUB 阅读器，提供阅读与系统 TTS 听书之间的句级定位。

当前源码版本：**0.1.5**。支持 **Android 8.0（API 26）及以上**。

## 下载安装

当前已发布的测试安装包为 **v0.1.5**，包含独立阅读与听书界面、快速起播和章节百分比进度。

- [下载 v0.1.5 Android APK](https://github.com/BestJerry/FreeReading/releases/download/v0.1.5/FreeReading-v0.1.5.apk)
- [版本说明与 SHA-256 校验文件](https://github.com/BestJerry/FreeReading/releases/tag/v0.1.5)

下载 APK 后，按 Android 系统提示允许该下载来源安装应用，即可安装。当前发布的是 **Debug 签名测试包**；同签名的已有测试版可覆盖安装，保留书架与进度。听书需在系统语音设置中安装对应语言的离线音色。本轮通过本地单测、构建和静态检查，未进行真机复测。

## 功能

| 功能 | 说明 |
| --- | --- |
| EPUB 书架 | 导入书籍，保存封面、目录与阅读进度；重复导入复用已有记录 |
| 外部打开与分享 | 从文件管理器打开 EPUB，或分享 EPUB 到 FreeReading，导入后进入阅读 |
| 阅读界面 | 正文优先，中央轻触展开目录／听书／设置，菜单叠加显示而不挤压或重新分页 |
| 独立听书页 | 封面、当前朗读内容、章节百分比、倍速及快进快退集中展示；返回阅读时继续播放 |
| 阅读设置 | 目录跳转、字号调整、纸色与夜读模式、翻页或连续滚动 |
| 系统 TTS 听书 | 使用手机已安装的离线音色，按需合成并缓存后续句子 |
| 原文同步 | 高亮当前句、跟随原文，以及长按选文后「从这里听」 |
| 播放控制 | 章节百分比、播放暂停、0.5～2 倍速、前后跳转 15 秒、句内进度恢复 |
| 后台播放 | 前台媒体服务承载播放，接入通知栏、锁屏与耳机控制 |

EPUB 解析与排版使用 Readium，音频播放与媒体会话使用 AndroidX Media3 / ExoPlayer。

## 快速使用

1. 点击书架中的「导入 EPUB」，或从文件管理器打开、分享 EPUB 到 FreeReading。
2. 打开书籍后默认进入纯净阅读。轻触正文中央或页脚可展开工具栏，从「目录」跳章，从「设置」调整字号、主题和滚动方式。
3. 点击「听书」进入独立播放器，再点击播放开始或继续。当前句准备好后即可播放，后续句子在后台缓存；章节百分比连续推进，暂停保留句内位置，手动选择目录后按新位置起播。
4. 播放器内「从阅读处听」从当前可见段落开头开始，跨页长段落也从段首开始。也可直接长按正文选择「从这里听」，指定所选文字所在的句子。
5. 在听书页调整倍速、前后跳转 15 秒或切换跟随原文；「返回阅读」只关闭播放器，音频继续播放。阅读页仅保留小听书入口，书架底部播放条也可直接进入听书页；「定位原文」返回正在朗读的位置。

系统 TTS 需要对应语言的**已安装离线音色**。缺少引擎或语音包时，可从应用进入系统语音设置处理。音质与语言支持由手机上的语音引擎决定。

仓库包含[原创示例 EPUB《山间来信》](samples/山间来信.epub)，可用于体验和自动回归测试。

### 外部打开的兼容范围

入口支持 EPUB MIME 类型。文件管理器返回通用 ZIP、二进制类型或未声明类型时，URI 路径需要带有 `.epub` 或 `.EPUB` 扩展名，系统才会提供对应的打开选项。

若来源既未声明 EPUB 类型、URI 路径又不含文件名，请使用书架内的「导入 EPUB」。外部 `content://` 文件需要来源授予读取权限。应用会先复制原文件，之后移动来源文件不影响已导入的书籍。

## 开发与构建

### 环境要求

- Android Studio，项目 Gradle JDK 选择 **JDK 17**。
- Android SDK Platform **36**。
- Gradle Wrapper **8.14**、Android Gradle Plugin **8.13.1**，已在仓库中配置。
- Kotlin **2.2.21**、Readium **3.1.2**、Media3 **1.9.2**。

在 Android Studio 中打开仓库根目录，安装缺少的 SDK 组件，确认项目 SDK 路径和 Gradle JDK 后运行 `app`。首次同步与构建需要联网下载依赖。

构建 Debug APK：

~~~bash
./gradlew :app:assembleDebug --no-daemon --max-workers=2
~~~

运行单测与静态检查：

~~~bash
./gradlew :app:testDebugUnitTest :app:lintDebug --no-daemon --max-workers=2
~~~

APK 输出至 `app/build/outputs/apk/debug/app-debug.apk`，可通过 Android Studio 安装到设备。Windows 使用 `gradlew.bat` 执行对应命令。

如果机器的全局 Java / Gradle 配置选择了其他 JDK，可仅为本次命令显式指定 JDK 17：

~~~bash
JAVA_HOME=/path/to/jdk17 ./gradlew -Dorg.gradle.java.home=/path/to/jdk17 :app:assembleDebug --no-daemon --max-workers=2
~~~

将示例路径替换为本机 JDK 17 目录。个人 JDK 与 Android SDK 的绝对路径应保留在本地环境配置中。

## 支持范围与限制

- 支持**无 DRM、可重排、以文本为主的 EPUB 2/3**。固定版式、扫描图片书、外部正文资源和加密内容不在当前支持范围内。导入原文件上限为 100 MB，正文与资源另有大小保护。
- 原文同步为**句级**。定位使用资源、元素与文本上下文，字号变化后可恢复阅读位置。段落起播不等于从屏幕最上方的单个字开始。
- 按句合成音频，当前句准备好即可起播，并提前缓存少量后续句子；无须等待整章音频生成。首次使用系统语音引擎或遇到未缓存的句子时，仍可能短暂准备。
- 章节边界沿用 EPUB 的正文资源顺序。同一 XHTML 中的多个目录锚点目前合并计算进度。应用内显示章节百分比；系统媒体会话仍以句子组织音频。
- 暂停、倍速和跳转使用实际音频位置。全书尚未生成音频时，不提供确定的全书音频总时长。
- 章节百分比按正文长度加权，结合当前句内的实际音频进度连续推进；它表示正文位置，不代表整章音频时间比例。缓存上限为 256 MB，旧缓存可按需回收。
- 语音缓存可被系统回收，再次播放时会重新生成；缓存不作为永久有声书导出。
- 后台播放受 Android 与厂商电池管理策略影响。用户强制停止应用后，需要重新打开才能继续。

## 数据与隐私

书籍原文件、封面、正文索引、阅读进度和语音缓存均保存在应用的本地私有目录。移除书籍会删除相应进度与缓存；卸载应用会清除这些本地数据，当前没有云端同步。

应用未申请 `INTERNET` 权限，也不申请全盘文件访问权限。TTS 按引擎报告的属性筛选已安装、无需联网的声音；语音包下载和第三方引擎的数据处理由系统设置及对应引擎负责。

## 项目结构

应用源码位于 `app/src/main/java/com/freereading/`：

| 路径 | 职责 |
| --- | --- |
| `data/` | 书架、本地文件、去重导入、正文索引与原子进度保存 |
| `epub/` | EPUB 格式校验、Readium 打开与确定性分句 |
| `reader/` | 阅读页面、目录、排版、句子高亮、定位与起播策略 |
| `importing/` | 系统打开与分享入口、导入任务及导入后的阅读跳转 |
| `audio/` | 离线 TTS、语言匹配、音频缓存、后台媒体服务与跨句跳转 |
| `ui/` | Compose 应用主题 |

其他目录：

- `app/src/test/`：JVM / Robolectric 回归测试与 EPUB 测试样本。
- `app/src/androidTest/`：需要真实语音引擎的设备端回归测试。
- `samples/`：原创示例 EPUB。
- `docs/`：故障诊断、修复边界与验证记录。

0.1.5 的本地验证：

- **18 个测试类、164 条测试通过**，包括本地 Robolectric / Compose UI 回归；Debug APK 构建成功，Lint 无错误。
- 验证默认阅读工具栏折叠、独立听书入口与控制回调、关闭播放器不停止音频、加载期间已有音频仍可控制，以及横屏滚动。
- 原生布局回归验证正文高度不随工具栏显示／隐藏变化，只为薄页脚保留空间；触摸回归验证页脚按钮的热区不会向上侵入正文。
- 结束听书或操作主播放按钮会取消尚未完成的正文／选文定位，避免旧任务迟到后重新起播；加载期间停止的句内进度可跨页面重建恢复。
- 音频准备失败后保留重试位置和章节进度；准备期间调整倍速可立即反映到界面。
- 本轮仅运行本地单测与构建检查，没有连接或操作真机。设备回归用例保留，按需运行。

0.1.4 的快速起播与章节百分比验证：

- **13 个测试类、125 条自动测试通过**，无失败、错误或跳过。
- 荣耀真机设备回归通过（1 项测试、七个阶段完整）：原创首章共 16 句，首个播放就绪时仅生成 1 个 WAV，确认无需等待整章合成。本次记录起播耗时为 **1,407 ms**，该数字为本次设备实测。
- 自然换句后章节进度从 0% 推进到约 6.59%，没有逐句归零；暂停时保持稳定，恢复后继续增加。暂停中快进 15 秒后进度推进至约 30.93%，切到下一章时从 0% 开始。

0.1.2 的本地验证记录：

- **12 个测试类、106 条自动测试通过**；Debug APK 构建成功，Lint 无错误，仍有警告与提示。

长时间熄屏、飞行模式、来电与耳机中断，以及跨厂商省电策略仍需专项真机验证。后台播放相关能力已有实现，具体兼容性以对应设备验证结果为准。
